# Pet Sprites

Add your pet sprite images here with the following naming convention:

## Required Files

| Filename | Description |
|----------|-------------|
| `egg.png` | Stage 0 - Healthy egg |
| `egg-weak.png` | Stage 0 - Weakened egg |
| `hatchling.png` | Stage 1 - Healthy hatchling |
| `hatchling-weak.png` | Stage 1 - Weakened hatchling |
| `juvenile.png` | Stage 2 - Healthy juvenile |
| `juvenile-weak.png` | Stage 2 - Weakened juvenile |
| `adult.png` | Stage 3 - Healthy adult |
| `adult-weak.png` | Stage 3 - Weakened adult |
| `legendary.png` | Stage 4 - Healthy legendary |
| `legendary-weak.png` | Stage 4 - Weakened legendary |

## Recommended Specs

- **Format:** PNG with transparency
- **Size:** 256x256px or 512x512px (square)
- **Style:** Consistent art style across all stages

## Placeholder

Until you add sprites, the UI will display emoji placeholders:
- 🥚 Egg
- 🐣 Hatchling  
- 🐤 Juvenile
- 🦅 Adult
- 🐉 Legendary
